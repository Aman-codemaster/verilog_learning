Verilog RTL Learning

A collection of Verilog RTL designs and simulations built while learning digital design and RTL development.

#Topics Covered

- Logic Gates
- Adders & Subtractors
- Multiplexers (MUX)
- Decoders
- Demultiplexers (DEMUX)
- Encoders
- Sequential Logic
- FSMs

 #Tools

- Verilog
- Icarus Verilog
- Surfer (Waveform Viewer)

#Purpose

This repository documents my hands-on journey from basic digital logic to RTL design, with each module tested through simulation and waveforms.

More designs and larger RTL projects will be added as I progress.
